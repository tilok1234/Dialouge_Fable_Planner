## Scope

The dialogue pipeline, still on the mock (Q-A1 — no key, no network). Per
ARCHITECTURE §2.2, generation is **two calls**, not one: a beat plan is produced
first, then prose is drafted from the approved beat plan. This separation
prevents attractive individual lines from displacing the scene's narrative
purpose.

This milestone:
- Implements `MockProvider.planScene` and `MockProvider.generateDialogue`
  (the two M4 methods; `reviewDialogue`/`repairDialogue` remain M6).
- Adds orchestration in `@df/generation`: scene+context → beat plan → draft,
  each stage validate-before-store (constraint #12).
- Wires endpoints + a UI "Generate dialogue" flow.
- Proves the **knowledge gate**: a draft that references a forbidden fact is
  flagged (the mock deliberately stays within the permitted set; a planted
  forbidden reference is rejected by the orchestrator's check).
