## Scope (from docs/ACCEPTANCE_TESTS.md §M1 + docs/OPEN_QUESTIONS.md §7)

Closes the schema gaps surfaced in Phase 0 Step F and lands the first I/O layer:

- **Q-F1 (blocking):** a `ContextPackage` schema. It's the single most-inspected
  artifact when a generation goes wrong (ARCHITECTURE §5) and is currently
  unvalidated. The existing `samples/.../context/golem-first-encounter.ctx.json`
  gives the shape to derive it from.
- **Q-F2:** `Terminology` and `TimelineEvent` schemas so `canon/terminology.json`
  and `canon/timeline.json` are contract-validated (currently loose arrays).
- **Q-E5:** referential integrity at the **storage** layer — refs that should
  point at existing ids (relationship.partyA → character, scene.participants →
  character+state, quest.stage transitions → stages, etc.). The schema layer
  can't know which ids exist; storage can.
- **@df/storage:** a reader/writer for the REPO_LAYOUT §4 on-disk project tree,
  with round-trip semantics (write then read deep-equals).
- **CI:** bump Node 20 → 22 (GitHub deprecation notice from M0 CI run).
