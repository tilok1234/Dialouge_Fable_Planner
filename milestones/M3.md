## Scope decision (Q-A1 — no API keys, no paid calls)

**The application never makes a real LLM call.** No `GLM_API_KEY`, no network
egress to a model provider. Every code path — including the UI's Generate
button — uses a deterministic **MockProvider** that returns canned, schema-valid
output. The full generation pipeline (interface, validation, locking, approval)
is built and tested against the mock; only the *source* of generated text is
mocked rather than a live model.

This is recorded as contract amendment **Q-A1** in `docs/OPEN_QUESTIONS.md` §8.
It supersedes any earlier implication that GLM-5.2 is wired by default.
`@df/providers` ships the interface + the mock; **no GLM client code is written.**
