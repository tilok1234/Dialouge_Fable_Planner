## Scope

The "so what" milestone: produce artifacts a real game can load. Per
docs/ACCEPTANCE_TESTS.md §M7 + PRODUCT_CONTRACT §10:

- **Generic JSON** (engine-agnostic). Only `approvalStatus === "accepted"`
  dialogue leaves the tool (drafts/patches/rejected never export — contract).
  Every exported line carries a **stable localization key** so external
  tooling/translators can localize later. Engine-agnostic: no Unity/Godot/Unreal
  keys.
- **CSV**: a flat spreadsheet of dialogue lines (one row per line), safe to
  round-trip through a spreadsheet app.

Lands in `@df/exporters` (the last empty package). Pure, no I/O of its own —
takes a project, returns strings/blobs; the backend writes them to disk / sends
them to the UI. Still mock-only on the generation side (Q-A1) — export reads
whatever's accepted, regardless of source.
