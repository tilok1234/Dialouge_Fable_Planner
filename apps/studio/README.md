# @df/studio

The Dialogue Foundry application: a React + Vite UI backed by a Node service
that hosts the generation pipeline, filesystem access, and the model provider.

**Status: M0 placeholder.** This package is wired into the pnpm workspace so
dependency resolution and import boundaries are defined from day one, but its
real UI/service code lands in **M2 (local editor)**. See
`docs/REPO_LAYOUT.md` §2 for the planned structure.
